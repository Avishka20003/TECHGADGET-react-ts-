# TechGadget Store - E-Commerce Platform

A robust web application designed for browsing, managing, and purchasing tech gadgets, built using the **MERN stack** (MongoDB, Express.js, React, Node.js).

## 🚀 Key Features

*   **User Authentication:** Secure login/signup system using JWT (JSON Web Tokens).
*   **Product Management:** Admin dashboard to Create, Read, Update, and Delete (CRUD) gadgets.
*   **Order System:** Seamless order placement with detailed invoice generation.
*   **Responsive UI:** A modern, clean frontend built with React and Vite.
*   **Role-Based Access:** Separate access levels for Admins and Customers.

## 🛠 Tech Stack

### Frontend
*   **Framework:** React.js
*   **Build Tool:** Vite
*   **Language:** TypeScript
*   **Styling:** CSS

### Backend
*   **Runtime:** Node.js
*   **Framework:** Express.js
*   **Database:** MongoDB with Mongoose
